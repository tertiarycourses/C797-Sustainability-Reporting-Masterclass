# Activity 3 Worksheet — Disclosure Control and Crosswalk

## Exact procedure

1. Open `mock-data/mock-data.csv`. Flag stale records older than the reporting cadence and estimates without a documented method.
2. Create a trace for each metric: source → transformation/calculation → reviewer → disclosure location → retained evidence.
3. Map each metric to the relevant requirement: IFRS S1 governance/strategy/risk/metrics, IFRS S2 climate metrics, GRI topic standard, and SGX climate reporting provisions.
4. Score control risk: `likelihood (1–5) × disclosure impact (1–5)`. Scores ≥15 require escalation before disclosure; 8–14 require remediation; ≤7 monitor.
5. Design the control in six fields: owner, frequency, input, action, retained evidence, escalation threshold.
6. Write the assertion boundary: “Based on [records] for [period/entity boundary], management can assert [claim]; [limitation] remains.”
