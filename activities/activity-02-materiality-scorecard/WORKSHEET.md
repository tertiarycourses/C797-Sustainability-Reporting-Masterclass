# Activity 2 Worksheet — Materiality and Scorecard

## Exact procedure

1. Open `mock-data/mock-data.csv`; verify the stakeholder evidence, date and reliability before using a score.
2. Plot each issue at `(enterprise impact, stakeholder significance)` on a 5×5 matrix.
3. Classify priority: both scores ≥4 = strategic priority; either score ≥4 = monitor/engage; both <4 = watchlist.
4. Calculate a confidence-adjusted priority: `significance × impact × reliability / 5`. Worked example for climate transition: `5 × 5 × 4 / 5 = 20`.
5. For each strategic priority, define one KPI with numerator, denominator, unit, reporting boundary, baseline year, 2030 target, owner and source system.
6. Set the traffic-light rule: green ≥target; amber within 5 percentage points below target; red >5 points below target.
